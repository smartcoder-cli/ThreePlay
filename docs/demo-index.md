# Demo Index

## Overview

ThreePlay currently contains 18 interactive demos.

## Core Demos

### 01. Basic Scene

- Topic: minimal Three.js scene structure
- Focus: scene, camera, renderer, material switching, camera type comparison

### 02. Geometries

- Topic: common geometry primitives
- Focus: topology, segments, wireframe, normal helper, vertex/triangle counts

### 03. Materials

- Topic: material model comparison
- Focus: Standard, Basic, Normal, Phong, Lambert, Toon, plus procedural textures

### 04. Lighting

- Topic: light and shadow behavior
- Focus: directional, point, spot, ambient, plus light position and shadow settings

### 05. Animation

- Topic: time-based animation
- Focus: rotation, bounce, scale, wave, and parameterized motion

### 06. Controls

- Topic: interaction schemes
- Focus: orbit, first-person, fly, transform controls, and object picking

## Interactive Demos

### 07. Particles

- Topic: point-based particle systems
- Focus: snow, fire, stars, fountain, count/size/speed/blending/gravity

### 08. Physics

- Topic: simplified rigid body behavior
- Focus: gravity, restitution, friction, spawning and clearing bodies
- Note: uses a lightweight custom approximation, not a full physics engine

### 09. Post Processing

- Topic: image-space effects
- Focus: bloom, film noise, sepia, pass composition

### 10. Model Loading

- Topic: model presentation workflow
- Focus: rotating and inspecting built-in placeholder shapes
- Note: uses primitives to stand in for external model loading concepts

### 11. Audio and Video

- Topic: media-reactive visuals
- Focus: generated audio analysis driving scale, position, and emissive response

### 12. Performance

- Topic: rendering cost and optimization knobs
- Focus: object count, instancing, culling, auto-rotation, live renderer stats

## Advanced Demos

### 13. Shaders

- Topic: custom shading
- Focus: shader modes, uniforms, color mixing, animated deformation

### 14. VR and AR

- Topic: immersive presentation concepts
- Focus: mono, stereo, overlay, room-scale style differences
- Note: concept simulation rather than full WebXR session integration

### 15. Terrain and Skybox

- Topic: atmosphere and environment shaping
- Focus: procedural terrain, sky presets, fog, terrain coloration, star visibility

### 16. WebGPU

- Topic: next-generation rendering concepts
- Focus: pipelines, buffers, compute, bind groups
- Note: compatibility-friendly conceptual demo, not a full WebGPU renderer path

### 17. Responsive

- Topic: responsive 3D composition
- Focus: fit, cover, portrait focus, landscape focus, and viewport-aware framing

### 18. Final Project

- Topic: combined showcase
- Focus: composition, animation, lighting, environment, and multi-object presentation

## Suggested browse order

If you want a broad tour rather than a course sequence:

1. `01` Basic Scene
2. `03` Materials
3. `06` Controls
4. `09` Post Processing
5. `11` Audio and Video
6. `13` Shaders
7. `15` Terrain and Skybox
8. `18` Final Project

## Notes

- All demos are browser-native ES modules.
- All demos are reachable from the homepage and support previous/next navigation.
- The site is structured as a gallery, so descriptions emphasize demo intent rather than curriculum progression.
